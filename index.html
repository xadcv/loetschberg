07

What is inside

One source system produces the colour font, the text sidecar, the local Regular TTF, and both web containers.

Two continuous axes

Weight runs from 100 to 900. Width runs from 75 to 125. Twelve masters define the grid.

Two independent alternates

ss01 selects Handdrawn. ss02 selects Extruded in the colour font. Either switch can be used alone.

A separate local outline

The Regular TTF joins overlapping pieces at every master. The visible geometry and advances still match the web face.
